# Backlog ejecutable del MVP

## Reglas

- Los puntos expresan complejidad relativa, no días.
- El calendario depende de equipo y velocidad observada.
- Cada historia hereda Definition of Done, seguridad, tenancy, observabilidad y
  documentación.
- Una historia que introduzca control remoto, Kubernetes o módulo diferido debe
  rechazarse o pasar por change request y ADR.
